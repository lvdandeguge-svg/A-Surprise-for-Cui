# 19岁生日网页部署说明

## 上传内容

将本目录中的以下内容上传到 GitHub 仓库根目录：

```text
index.html
music\
```

`music` 目录必须与 `index.html` 保持相对位置不变。

原背景音乐请继续保留在 GitHub 仓库根目录，文件名为：

```text
Dear John.mp3
```

它不要放进 `music` 目录。页面会优先把 `music` 目录用作 16 首点播礼物。

## GitHub Pages

1. 上传完成后，在仓库的 **Settings → Pages** 中启用 GitHub Pages。
2. 选择要发布的分支和根目录。
3. 等待 GitHub Pages 完成部署。
4. 使用部署后的 HTTPS 链接生成 NFC 标签或分享链接。

## 已包含内容

- 16 首点播歌曲，统一输出为浏览器兼容的 MP3。
- 16 张从原音乐文件提取的专辑封面。
- 10 首时间轴歌词、2 首普通歌词。
- 没有歌词的歌曲会显示“纯音乐，用心感受”。
- 唱片墙直接显示全部歌名，点击后再进入播放界面。

## 不要上传

以下源文件仅用于制作，不需要上传到 GitHub：

```text
music-sources
flac-sources
work
```

## 注意

- `music\playlist.js`、`music\covers` 和 16 个 MP3 都不能遗漏。
- 如果以后替换歌曲，需要同时更新 `music\playlist.js`。
- GitHub 仓库根目录原有的 `Dear John.mp3` 请保留，否则前面的背景音乐会无法播放。
